# SmartWallet AI - NEXORA 2026

Your money should explain itself.

## Architecture

SmartWallet AI is built on a strict 3-tier architecture:

- **Tier 1 (Presentation):** Next.js (App Router), Tailwind CSS
- **Tier 2 (Application/Business Logic):** Cloudflare Workers, Hono
- **Tier 3 (Data Access):** Cloudflare D1, R2

## Local Development

```bash
npm install
npm run dev
```
